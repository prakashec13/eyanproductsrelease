# Eyan Products Android releases

Signed Android releases for Eyan Products Manager.

## Version 1.0.2 (revision 3)

[Download the APK](https://raw.githubusercontent.com/prakashec13/eyanproductsrelease/main/releases/v1.0.2-3/app-release.apk)

- Keep inventory search and its result count readable on desktop.
- Show appropriate category icons for oils, grains, spices, health mixes, sweeteners, and personal care.
- Package: com.eyanproducts.manager.

SHA256SUMS.txt verifies the APK. release_manifest.json contains the current version, public URL, checksum, and size. Versioned APK files are immutable.
