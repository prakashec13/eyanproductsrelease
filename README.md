# Eyan Products Android releases

Signed Android releases for Eyan Products Manager.

## Version 1.0.5 (revision 6)

[Download the APK](https://raw.githubusercontent.com/prakashec13/eyanproductsrelease/main/releases/v1.0.5-6/app-release.apk)

- Improved thermal receipts and optional invoice lookup QR codes.
- Eyan logo on QR product labels and updated attribution.
- Package: com.eyanproducts.manager.

SHA256SUMS.txt verifies the APK. release_manifest.json contains the current version, public URL, checksum, and size. Versioned APK files are immutable.
